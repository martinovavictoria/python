2.
Программа сохраняет результат функции. Если функция вызывается повторно с теми же аргументами — она не вычисляется заново, а берёт готовый результат из памяти.

В работе реализовано кеширование функций через декоратор.
Декоратор cache принимает функцию и создаёт словарь для хранения результатов.
При вызове формируется ключ из имени функции и аргументов.
Если результат уже вычислялся — он берётся из словаря.
Если нет — функция выполняется и результат сохраняется.
Использованы декораторы, словари, кортежи, *args и замыкание.

Замыкание - внутренняя функция использует переменную внешней функции

Кеш - память с готовыми результатами

Функция make_key
def make_key(func_name, *args):
    return (func_name,) + args

Создаёт уникальный ключ, принимает имя функции и любое количество аргументов и возваращет кортеж

Декоратор изменяет поведение функции, это функция, которая принимает другую функцию и изменяет или дополняет её поведение, не меняя код самой функции, декоратор = «обёртка» вокруг функции. Декораторы применяются снизу вверх.
Сначала @meat, потом @vegetables, потом @bread.
При вызове сначала выполняется внешний декоратор, затем внутренние и потом сама функция.

@cache
def calculate_sum(*numbers):

Это то же самое, что:

calculate_sum = cache(calculate_sum)

*numbers - позволяет передать любое количество чисел

*args - передаёт любое количество аргументов
**kwargs - именованные аргументы

func.__name__ - возвращает имя функции

3.
Программа создаёт декоратор, который: запускает функцию и если возникает ошибка — перезапускает её ещё раз. То есть автоматически повторяет выполнение при исключении.

В работе реализован декоратор retry_on_exception.
Он запускает функцию внутри блока try.
Если возникает исключение, декоратор повторяет вызов функции.
Для OSError дополнительно выводится сообщение в консоль.
Декоратор применён к чтению файла и функции деления.
Используются try/except, декораторы и работа с файлами.

sys - позволяет работать с потоком вывода. file=sys.stdout - это вывод текста в консоль.
